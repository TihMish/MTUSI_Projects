## 1. Как запустить программу

Программа на Python — это текстовый файл с расширением `.py`. Компилировать его не нужно, его сразу выполняет интерпретатор:

```
python3 hello.py
```

После запуска программа ждёт, пока ты введёшь данные с клавиатуры. Ввод одной строки заканчивается нажатием Enter.

Данные можно не набирать руками, а взять из файла, и вывод можно положить в файл. Эти две возможности называются перенаправлением; как оно записывается — в справочнике терминала.

Если программа запустилась и ничего не печатает — скорее всего, она не зависла, а ждёт от тебя ввод.

## 2. Как прочитать то, что ввели

Есть два способа прочитать одну строку.

```python
line = input()
```

`input()` читает строку и убирает перенос в конце. Если читать нечего, потому что ввод закончился, программа падает с ошибкой `EOFError`.

```python
import sys

line = sys.stdin.readline()
```

`sys.stdin` — это и есть стандартный поток ввода. Метод `readline()` читает строку вместе с переносом в конце, а когда ввод закончился, возвращает пустую строку и не падает.

Дальше строку обычно приводят в порядок:

| Что пишем | Что делает | Пример |
| --- | --- | --- |
| `line.strip()` | Убирает пробелы и перенос строки по краям | `"  42 \n"` → `"42"` |
| `line.split()` | Разбивает по пробелам, несколько пробелов подряд считает за один, возвращает список кусков | `"  7   3 "` → `['7', '3']` |
| `len(parts)` | Сколько кусков получилось | `len(['7', '3'])` → `2` |

Так проверяют, что чисел ровно столько, сколько нужно:

```python
parts = sys.stdin.readline().split()
# для пустой строки parts будет пустым списком, len(parts) == 0
```

## 3. Из строки в число

Из потока ввода всё приходит строкой. `"2" + "3"` даст `"23"`, а не `5`. Чтобы считать, строку надо превратить в число.

| Что пишем | Что получаем |
| --- | --- |
| `int("42")` | целое `42` |
| `int("-42")` | целое `-42` |
| `int("4.2")` | ошибка: `int` не понимает точку |
| `float("4.2")` | дробное `4.2` |
| `float("42")` | дробное `42.0` |
| `float("1,5")` | ошибка: десятичный разделитель в Python — точка, а не запятая |
| `str(42)` | строка `"42"` |

Если в строке не число, `int()` и `float()` не возвращают ничего осмысленного — они завершают программу с ошибкой. Поэтому проверять надо **до** преобразования.

## 4. Как проверить, что это вообще число

Обработка исключений может изучаться отдельно. Сегодня достаточно другого подхода: не допустить её, проверив строку заранее. Для этого хватает четырёх методов.

| Что пишем | Что делает | Пример |
| --- | --- | --- |
| `text.isdigit()` | `True`, если строка состоит только из цифр | `"42".isdigit()` → `True`, `"-42".isdigit()` → `False` |
| `text.startswith("-")` | `True`, если строка начинается с этого символа | `"-42".startswith("-")` → `True` |
| `text.count(".")` | Сколько раз символ встречается в строке | `"1.5".count(".")` → `1` |
| `text[1:]` | Строка без первого символа | `"-42"[1:]` → `"42"` |
| `text.replace(что, на_что)` | Возвращает строку, в которой один кусок заменён другим. Исходная строка не меняется | `"1.5".replace(".", "")` → `"15"` |

Готовый пример — проверка целого числа:

```python
def is_integer(text):
    if text.startswith("-") or text.startswith("+"):
        text = text[1:]
    return 1 <= len(text) <= 100 and text.isascii() and text.isdecimal()
```

`is_integer("42")` → `True`, `is_integer("-42")` → `True`, `is_integer("три")` → `False`, `is_integer("")` → `False`, `is_integer("-")` → `False`.

`isascii()` проверяет, что все символы входят в ASCII, `isdecimal()` — что это десятичные цифры. Вместе они пропускают только `0–9`. Одного `isdigit()` недостаточно: например, `²` оно принимает, но `int()` такое число не преобразует. Лимит 100 цифр — часть формата дня и проверяется до преобразования.

Для дробного числа правило другое: точек в нём ноль или одна, и одна точка не может быть единственным содержимым строки — `"."` числом не является, а `"42"` является. После удаления знака проверь число точек, убери точку через replace и проверь оставшиеся цифры тем же правилом ASCII и длины 1–100. Проверку для дробного собери сам.

## 5. Арифметика

| Знак | Что делает | Пример |
| --- | --- | --- |
| `+` `-` `*` | Сложение, вычитание, умножение | `7 * 3` → `21` |
| `/` | Деление. Всегда даёт дробное число | `6 / 3` → `2.0` |
| `//` | Деление нацело, округляет **вниз** | `7 // 2` → `3`, `-7 // 2` → `-4` |
| `%` | Остаток от деления | `7 % 2` → `1` |
| `**` | Возведение в степень | `3 ** 2` → `9` |
| `x ** 0.5` | Квадратный корень. Отдельная библиотека для этого не нужна | `9 ** 0.5` → `3.0` |
| `abs(x)` | Модуль числа, то есть значение без знака | `abs(-7)` → `7` |

Деление на ноль завершает программу с ошибкой `ZeroDivisionError`. Проверяй делитель до деления.

Внимание к `//` на отрицательных числах: `-7 // 2` даёт `-4`, потому что округление идёт вниз, к меньшему. Если по условию задачи нужно отбросить дробную часть, то есть получить `-3`, это другая операция — собери её через `abs()` и знак.

## 6. Условия

Условие — это развилка: если правда, делаем одно, иначе другое.

```python
if x > 0:
    print("больше нуля", end="")
elif x == 0:
    print("ноль", end="")
else:
    print("меньше нуля", end="")
```

Двоеточие в конце строки с `if` обязательно. Тело условия сдвигается вправо на четыре пробела — по этому сдвигу Python и понимает, что к чему относится. Табуляцию и пробелы в одном файле не смешивай.

| Что пишем | Что проверяем |
| --- | --- |
| `<` `<=` `>` `>=` | Меньше, меньше или равно, больше, больше или равно |
| `==` | Равно. Одиночное `=` — это не сравнение, а присваивание |
| `!=` | Не равно |
| `and` | Оба условия верны |
| `or` | Верно хотя бы одно |
| `not` | Отрицание |

Строгое сравнение и нестрогое — разные вещи. `x < 5` не пропускает значение ровно 5, `x <= 5` пропускает. Читай условие задачи внимательно: слово «строго» там стоит не случайно.

## 7. Вывод

```python
print("Hello")
```

`print` по умолчанию добавляет в конце перенос строки. Если по условию задания вывод не должен заканчиваться переносом, перенос надо отключить:

```python
print("Hello", end="")
```

| Что пишем | Что печатается |
| --- | --- |
| `print("a", "b")` | `a b` — значения разделяются пробелом |
| `print("a", "b", sep="")` | `ab` |
| `print("a", end="")` | `a` без переноса в конце |
| `print("Hello, " + str(42) + "!", end="")` | `Hello, 42!` — при склейке число надо перевести в строку |
| `print(f"Hello, {42}!", end="")` | то же самое, короче: в f-строке значение подставляется в фигурные скобки |

Проверить, есть ли лишний перенос в конце, глазами нельзя. Способ увидеть невидимые символы — в справочнике терминала.

## 8. Функции

Функция — это кусок программы с именем, который можно вызвать сколько угодно раз.

```python
def square(number):
    return number * number


print(square(4), end="")   # напечатает 16
```

`def` объявляет функцию, в скобках — что она принимает, `return` — что она отдаёт наружу. После `return` функция заканчивается.

Сегодня функции не обязательны, но одну проверку ввода удобно вынести в функцию и вызывать её для каждого числа, а не писать одно и то же дважды.

## 9. Ловушки дня

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Вывод совпадает на вид, а проверка не проходит | В конце лишний перенос строки | `print(..., end="")` |
| `could not convert string to float: '1,5'` | Запятая вместо точки | В этом дне запятая запрещена: верни n/a; не заменяй её точкой |
| Работает на `7 3`, падает на `  7   3  ` | Лишние пробелы | `strip()` и `split()` |
| На отрицательных числах результат меньше на единицу | `//` округляет вниз, а не отбрасывает дробную часть | См. раздел 5 |
| Программа падает на пустом вводе | `input()` не переживает конец ввода | `sys.stdin.readline()` |
| `0.1 + 0.2 == 0.3` даёт `False` | Дробные числа хранятся приближённо | Не сравнивай дробные на точное равенство. Если задачу можно решить без квадратного корня, реши без корня: корень добавляет погрешность |
| Ошибка про отступы, хотя всё выглядит ровно | Смешаны табуляция и пробелы | Везде четыре пробела |
| Программа молчит и не завершается | Она ждёт ввод | Введи строку и нажми Enter |

Текст любой ошибки ищи в `materials/traceback_40_rus.md` — там сказано, что она означает и что пробовать.

## 10. Перенос центра и практические изменения

Если центр передатчика `(cx, cy)`, смещения модуля относительно него — `x - cx` и `y - cy`. Квадрат расстояния — сумма квадратов этих смещений. Сравнивай его с квадратом радиуса. Строгое `<` исключает границу, `<=` включает. Для проверки выбирай центр, точку на границе и точку чуть дальше.

Префикс вывода — обычная строка перед прежним ответом. Порядок четырёх результатов определяется порядком аргументов print или последовательностью склеивания. На защите меняется правило, а проверка ввода сохраняется. До запуска вычисли один ожидаемый результат на бумаге или устно.
