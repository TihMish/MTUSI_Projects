# Python и SQL в этом проекте

SQL выбирает и считает данные. Python открывает файл базы, передаёт запросы и печатает результат. В задании 6 обе части должны быть твоими и понятными тебе.

## Что уже есть

Модуль sqlite3 входит в стандартную библиотеку Python, но конкретная рабочая установка должна содержать поддержку SQLite. Это заранее обеспечивает стафф. Отдельный сервер и программа sqlite3 в терминале не требуются.

Посмотри src/partner/example.py. В нём видно, как получить строки и пройти по ним циклом. Способ открыть существующую базу только для чтения показан в src/partner/common.py.

## Что написать самому

В src/report.sql сохрани SQL-запросы отчёта. В src/report.py прочитай этот файл, открой src/results.db в режиме чтения и выведи результаты с понятными подписями. Пути должны определяться относительно проекта, а не домашней папки автора.

Можно использовать готовую split_sql из src/partner/common.py для разделения файла на запросы. Наивное разделение по каждой точке с запятой портит SQL, если этот знак находится внутри строки. Использование этой функции разрешено; сами запросы и сборка отчёта остаются твоей работой.

Нужные инструменты SQL: JOIN для связи таблиц, GROUP BY для группировки, COUNT для количества, условный подсчёт для разных оценок. LEFT JOIN пригодится, чтобы показать dimension даже без оценок. Не забывай про разные цели подсчёта: случаи, попытки, оценки и пары.

Если используешь Python для ввода записей, передавай пользовательский текст параметрами. Не собирай SQL из вставленного ответа LLM. Для отчёта записи в базу вообще не нужны.

## Как проверить себя вручную

Открой несколько записей журнала. Посчитай их по выбранному dimension на бумаге. Сравни с отчётом. Попроси собеседника выбрать другую группу.

Проверь, что программа объясняет отсутствие базы, не падает на пустом журнале и не делит на ноль. Случаи без оценки не должны превращаться в успехи. Покажи, что повторные оценки по другим dimensions не увеличили число ответов.

Для проверки пустого журнала не удаляй рабочий файл. Создай отдельную временную базу по journal_schema.sql и разреши своей программе принимать путь к ней. Возможность передать путь — полезное дополнение, но не обязательный интерфейс.

Это ручная проверка твоей программы. В комплекте нет автотестов, скрытых эталонов и программ, выставляющих баллы.
