# Карточки edge cases

## Шаблон карточки

- **ID:** EC-XX
- **Название:** [краткое описание ситуации]
- **Связанная user story / требование:** [ID или текст]
- **Описание:** что именно происходит: какие входные данные, состояние системы, параллельные действия.
- **Критичность:** Высокая / Средняя / Низкая
- **Ожидаемое поведение системы:** как система должна реагировать, какие сообщения выводить, как восстанавливать состояние.
- **Примечания:** дополнительные соображения.

## Примеры универсальных карточек (адаптируй под свой кейс)

### EC-01. Конфликт одновременного доступа к ресурсу
- **Название:** Два пользователя одновременно пытаются занять один и тот же слот/ресурс.
- **Связанная user story:** Создание бронирования.
- **Описание:** Пользователь А и пользователь Б одновременно отправляют запрос на бронирование одного и того же временного слота (или последнего доступного экземпляра ресурса). Оба видят его как свободный в момент загрузки интерфейса.
- **Критичность:** Высокая
- **Ожидаемое поведение системы:** Обработать запросы строго последовательно. Первый успешно создаёт бронь. Второй получает сообщение «Выбранное время/ресурс только что заняли. Пожалуйста, обновите страницу и выберите другой вариант».
- **Примечания:** Важно чтобы система не допустила двойного бронирования ни при каких условиях.
