# Вопросы для общей приёмки

Это открытый набор подсказок проверяющему. Он дополняет двадцать пять пунктов рубрики,
не создаёт отдельный экзамен или дополнительные обязательные задания.
Вопросы можно адресовать представителю группы, присутствующие могут дополнять.
Не требуется задать каждый вопрос каждому участнику.

| Тема | Вопрос | Признак понимания |
|---|---|---|
| Перепись | Почему запись с двумя структурными ошибками считается один раз? | Показывает границу записи и формулу счётчиков |
| Связи | Что происходит при повторённом ID? | Исключаются все записи с этим ID |
| Варианты | Что будет, если переставить буквы при показе, но оставить старый ключ? | Понимает связь метки и текста |
| Ввод | Чем пустая строка отличается от EOF? | Различает пустой ответ и конец потока |
| Код | Что будет со строкой ОТВЕТ: внутри фрагмента? | Она показана с префиксом > и не является маркером ввода |
| Адаптивность | Покажите решение после конкретного верного и неверного ответа | Сходится с policy.md и реальным кодом |
| Знания | Почему пустой ответ после верного не сужает множество знаний? | Не приписывает ошибку знания неверному формату |
| Исчерпание | У целевого уровня кончились вопросы. Что дальше? | Понятная замена или объяснённый отказ, без падения |
| Ревизия | Объясните одно удаление и один сохранённый вопрос | Приводит факт, а не только номер из ключа |
| Ревизия | Почему удаление этого вопроса меняет измерение? | Называет последствие, а не только дефект |
| Свой вопрос | Почему неверный вариант действительно неверен? | Проверяет ключ по условиям вопроса |
| Уверенность | Что означает 1.00 у вашей программы? | Описывает свою меру и её ограничения |

Если нужна маленькая проверка с поломкой, используйте временную копию:
удалите ответы исправного one/many/short или один уровень. Не изменяйте сданный
commit и не требуйте незаявленной точности на банке с удалённым уровнем.
