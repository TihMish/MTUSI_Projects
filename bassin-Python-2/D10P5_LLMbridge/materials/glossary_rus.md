# Словарь

**Агент** — программа, которая получает задачу, сама выбирает инструменты и вызывает их, пока не получит результат.

**Аргументы** — значения, с которыми вызывают инструмент: например, идентификатор участника и название товара.

**Внедрение инструкций (prompt injection)** — приём, при котором в обычный на вид текст прячут указание агенту. Агент читает его как поручение, потому что для модели весь текст одинаков.

**Инструмент (tool)** — именованная операция, доступная агенту: `get_coin_balance`, `create_order`. У инструмента есть имя, описание и список аргументов.

**Журнал (log)** — файл, в который записывается каждый вызов: время, инструмент, аргументы, ответ.

**JSON** — формат записи данных в виде пар «ключ — значение». В Python превращается в словарь функцией `json.loads`.

**JSONL** — файл, в каждой строке которого отдельная запись JSON.

**Код отказа** — короткое слово, которым сервер объясняет, почему не выполнил вызов: `OUT_OF_STOCK`, `USER_LIMIT_EXCEEDED`.

**Коины** — внутренняя валюта Лавки, за которую покупают мерч.

**MCP** — протокол, по которому программа узнаёт, какие инструменты предоставляет сервер, и вызывает их.

**Необратимое действие** — действие, которое нельзя отменить следующим сообщением: списание, отмена чужого заказа, отметка о выдаче.

**Системный промпт** — текст, который агент получает перед разговором: кто он, что делает, чего не делает.

**Словарь (dict)** — структура данных в Python: набор пар «ключ — значение», значение достаётся по ключу в квадратных скобках.

**Вариант** — один из нескольких наборов материалов расследования. Буква варианта написана на бумажной карточке помощника и вписывается в `src/variant.txt`.

**Хронология (timeline)** — восстановленный порядок событий с временными отметками. Основной результат разбора инцидента.
