# Разбор журнала программой

Журнал твоего варианта лежит в `datasets/<буква>/logs/agent.jsonl`, где буква — та, что на бумажной карточке помощника. Например, для варианта B это `datasets/B/logs/agent.jsonl`.

Расширение `jsonl` означает: в каждой строке отдельная запись в формате JSON.

## Одна строка журнала

~~~
{"time": "2026-09-16T11:04:12", "tool": "create_order", "args": {"user_id": "student_03", "product_id": "bottle", "size": "one_size"}, "result": {"ok": true, "data": {"order_id": "ord-0041", "status": "created", "total_price": 150}}}
~~~

Читается так: в 11:04:12 помощник вызвал `create_order` с аргументами и получил успешный ответ с номером заказа.

## Как превратить строку в данные

Модуль `json` из стандартной библиотеки превращает текст в словарь:

~~~python
import json

строка = '{"tool": "create_order", "time": "11:04:12"}'
запись = json.loads(строка)
print(запись["tool"])    # create_order
print(запись["time"])    # 11:04:12
~~~

Словарь — это набор пар «ключ — значение». Значение достаётся по ключу в квадратных скобках. Значение само может быть словарём, тогда скобки идут подряд:

~~~python
print(запись["args"]["user_id"])
print(запись["result"]["ok"])
~~~

## Прочитать весь журнал

~~~python
import json

записи = []
with open("datasets/B/logs/agent.jsonl", encoding="utf-8") as файл:
    for строка in файл:
        записи.append(json.loads(строка))

print(len(записи))
~~~

Подставь свою букву вместо `B`. Если не хочешь править путь руками, прочитай букву из файла:

~~~python
буква = open("src/variant.txt", encoding="utf-8").read().strip()
путь = "datasets/" + буква + "/logs/agent.jsonl"
~~~

Дальше работаешь со списком словарей обычными циклами и условиями.

## Накопить счётчик

Готовый пример этого приёма — `src/partner/example.py`. Запусти его и посмотри, что он печатает.

~~~python
счётчик = {}
for запись in записи:
    имя = запись["tool"]
    счётчик[имя] = счётчик.get(имя, 0) + 1
~~~

`счётчик.get(имя, 0)` возвращает текущее значение, а если ключа ещё нет — ноль.

## Осторожно

**Не у каждой записи есть `data`.** У неуспешного вызова вместо `data` лежит `error`. Проверяй `запись["result"]["ok"]` прежде, чем лезть в `data`, иначе программа упадёт с `KeyError`.

**Время — строка, а не число.** Строки вида `2026-09-16T11:04:12` сравниваются между собой как обычные строки и при этом сортируются правильно. Превращать их во что-то другое не обязательно.

**Порядок записей в файле — это порядок событий.** Отдельно сортировать не нужно.

## Как найти самую длинную серию подряд

Приём, который пригодится: идти по списку, накапливать текущую серию, а когда она прерывается — сравнивать с самой длинной из найденных.

~~~python
самая_длинная = []
текущая = []
for запись in записи:
    if подходит(запись):
        текущая.append(запись)
    else:
        if len(текущая) > len(самая_длинная):
            самая_длинная = текущая
        текущая = []
~~~

После цикла проверь текущую серию ещё раз: она могла дойти до конца файла и не прерваться.
