# Разборник ошибок. Топ-40

Ошибка — это не наказание, а сообщение. В нём почти всегда написано, что случилось и в какой строке. Сегодняшняя задача — научиться его читать: завтра сосед выберет запись из твоего журнала и попросит воспроизвести ошибку в терминале.

## Как читать traceback

```
Traceback (most recent call last):
  File "/home/user/project/src/calc.py", line 2, in <module>
    print(int(x) + 1)
          ^^^^^^
ValueError: invalid literal for int() with base 10: 'три'
```

Читай снизу вверх:

1. **Последняя строка — самая важная.** До двоеточия тип ошибки (`ValueError`), после — что именно не так (`'три'` не превращается в число).
2. **Строка со стрелочками** показывает место в коде, где сломалось: `int(x)`.
3. **Строка `File ... line 2`** — файл и номер строки.
4. Всё, что выше, — путь, по которому программа туда пришла. Пока программа в один файл, это одна строка `in <module>`.

Слово `Traceback` в начале означает, что программа запустилась и упала по дороге. Если слова `Traceback` нет, а есть `SyntaxError` или `IndentationError`, — программа не запустилась вообще: Python не смог её прочитать.

Ниже — что означают сорок самых частых сообщений. Ищи по тексту после типа ошибки.

## Программа не запускается: отвечает терминал, а не Python

| № | Сообщение | Что означает | Что попробовать |
| --- | --- | --- | --- |
| 1 | `bash: python: command not found` | Команды `python` на станции нет | Запускай через `python3` |
| 2 | `python3: can't open file '/.../hello.py': [Errno 2] No such file or directory` | Питон не нашёл файл с таким именем | Проверь, в той ли ты папке и так ли называется файл. Опечатка в имени — самая частая причина |
| 3 | `bash: ./hello.py: Permission denied` | У файла нет права на выполнение | Либо выдай право, либо запускай через `python3 hello.py` — так право не нужно |
| 4 | `hello.py: line 2: syntax error near unexpected token ...` | Ты запустил питоновский файл командой `bash`. Bash пытается читать код Python как свои команды | Запускай `python3 hello.py` |
| 5 | `SyntaxError: Missing parentheses in call to 'print'. Did you mean print(...)?` | Код написан по правилам Python 2 | В Python 3 у `print` есть скобки: `print("a")` |

## Python не смог прочитать программу

| № | Сообщение | Что означает | Что попробовать |
| --- | --- | --- | --- |
| 6 | `SyntaxError: expected ':'` | Забыто двоеточие в конце строки с `if`, `else`, `def` | Поставь `:` в конце этой строки |
| 7 | `SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?` | В условии написано одиночное `=` — это присваивание, а не сравнение | В сравнении пиши `==` |
| 8 | `SyntaxError: '(' was never closed` | Открыта скобка и не закрыта | Найди указанную строку и закрой скобку. Часто ошибка на строку выше указанной |
| 9 | `SyntaxError: unterminated string literal (detected at line N)` | Кавычка открыта и не закрыта | Закрой кавычку. Открывающая и закрывающая должны быть одинаковыми |
| 10 | `SyntaxError: invalid syntax` без пояснений | Python дошёл до места, которое не может разобрать | Смотри указанную строку и строку прямо перед ней |
| 11 | `IndentationError: expected an indented block after 'if' statement on line N` | После `if` тело не сдвинуто вправо | Сдвинь строки тела на четыре пробела |
| 12 | `IndentationError: unexpected indent` | Строка сдвинута вправо там, где сдвиг не нужен | Убери лишние пробелы в начале строки |
| 13 | `TabError: inconsistent use of tabs and spaces in indentation` | В отступах смешаны табуляция и пробелы | Сделай везде четыре пробела. Глазами это не видно, ищи заменой табов на пробелы |

## Если ошибки нет, а результат неверный

Такое не попадает в traceback, поэтому здесь отдельно.

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Вывод совпадает на вид, но проверка не проходит | Лишний перенос строки в конце | `print(..., end="")` |
| Программа ничего не печатает и не завершается | Ждёт ввод | Введи строку и нажми Enter |
| На отрицательных числах результат меньше на единицу | `//` округляет вниз | Раздел 5 методички дня |
| Сравнение дробных даёт неожиданный результат | Дробные хранятся приближённо | Не сравнивай их на точное равенство |

Каждый такой случай — тоже запись в журнал ошибок. Строка «ошибки не было, но результат расходился с эталоном» стоит там ровно столько же, сколько traceback.
