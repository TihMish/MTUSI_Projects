# Образец журнала ошибок

Журнал сквозной на всю неделю: вчерашний `errors.md` копируется в сегодняшний `src/` и продолжается. Вчерашнего нет — заводится новый по этому образцу.

**Формат записи — три строки:** текст ошибки как есть, что она означала, что ты сделал.

Пиши по ходу дня. Журнал, написанный вечером по памяти, отличим с первого взгляда: в нём нет настоящих текстов ошибок, а есть пересказ.

Записей должно быть не меньше пяти. Если ошибок было меньше — добери успешными проверками: команда, результат, «прошло с первого раза». Выдумывать ошибку не нужно.

Завтра проверяющий выберет одну запись и попросит воспроизвести её в терминале. Записи вроде «была ошибка, исправил» на этой проверке не выживают.

---

## 1. Программа останавливается на первой битой записи

```
Traceback (most recent call last):
  File "src/memory.py", line 34, in classify
    return None, name, float(value)
ValueError: could not convert string to float: '21,4'
```
Что означала: в значении запятая вместо точки, `float` такое не принимает.
Что сделал: проверяю строку до преобразования, по разделу 4 справочника формата. Запись уходит в счётчик `значение не число`.

## 2. Счётчики разошлись с эталоном на две записи

Команда: `python3 src/partner/verify.py src/main.py --task 4`
Что означало: строку `09:12:05;;21,4` я посчитал дважды — и в `пустое имя модуля`, и в `значение не число`.
Что сделал: одна запись даёт ровно одну причину, первую по порядку проверок. Вернул после первой сработавшей.

## 3. Отчёт в файле оказался испорчен

Команда: `python3 src/main.py datasets/memory.log > src/report.txt`
Что означало: причины отбраковки печатались в стандартный вывод и попали в файл вместе с таблицей.
Что сделал: причины теперь идут в поток ошибок, `file=sys.stderr`.

## 4. Линтер ругается на модуль

```
src/memory.py:52: L020 модуль не должен печатать: печатает точка входа
```
Что означала: я оставил в `memory.py` отладочный `print`.
Что сделал: убрал. Отладочную печать делаю в `main.py` и убираю до сдачи.

## 5. Проверка прошла с первого раза

Команда: `python3 src/partner/lint.py src`
Результат: `Замечаний нет.`
Прошло с первого раза.
