## 1. Аргументы командной строки

То, что написано после имени программы, приходит в список `sys.argv`.

```python
import sys

print(sys.argv)
```

Запуск `python3 src/main.py datasets/memory.log --scan` даёт список из трёх элементов: нулевой — имя самой программы, дальше путь и флаг.

| Что пишем | Что получаем |
| --- | --- |
| `sys.argv[0]` | имя запущенной программы |
| `sys.argv[1:]` | всё, что передал пользователь |
| `len(sys.argv)` | сколько всего элементов |

Проверяй, что аргументы вообще пришли: обращение к `sys.argv[1]`, когда его нет, останавливает программу.

## 2. Чтение файла

```python
with open(path, encoding="utf-8") as source:
    text = source.read()
```

`with` сам закрывает файл, когда блок кончается. Кодировку указывать обязательно: без неё программа зависит от настроек станции.

Разделить прочитанное на строки и убрать пустой хвост от завершающего перевода строки:

```python
lines = text.split("\n")
if lines and lines[-1] == "":
    lines.pop()
```

Файл можно читать и построчно, тогда перевод строки остаётся в конце каждой строки и его снимают `rstrip("\n")`.

## 3. Списки

| Что пишем | Что делает |
| --- | --- |
| `items = []` | пустой список |
| `items.append(x)` | добавить в конец |
| `len(items)` | сколько элементов |
| `items[0]` · `items[-1]` | первый и последний |
| `sum(items)` | сумма чисел |
| `for item in items:` | перебрать |
| `"a;b".split(";")` | разбить строку в список |
| `";".join(parts)` | склеить список в строку |

Пустой список в условии считается ложью: `if not values:` — это «значений нет».

## 4. Словари

Словарь хранит пары «ключ — значение». Ключом здесь будет имя модуля.

```python
counts = {}
for name in names:
    counts[name] = counts.get(name, 0) + 1
```

`get(ключ, значение_по_умолчанию)` возвращает значение или умолчание, если ключа нет. Без него обращение к несуществующему ключу останавливает программу.

| Что пишем | Что делает |
| --- | --- |
| `d[key] = value` | положить |
| `d.get(key, 0)` | взять или умолчание |
| `d.setdefault(key, [])` | если ключа нет — создать с этим значением |
| `key in d` | есть ли ключ |
| `d.items()` | пары ключ-значение |
| `sorted(d)` | ключи по порядку |

Чтобы копить списки значений по модулям:

```python
values.setdefault(name, []).append(number)
```

## 5. Сортировка

```python
order = sorted(counts)
```

По умолчанию сортирует по возрастанию. Для строк это порядок кодов символов: заглавные буквы идут раньше строчных, поэтому `SENSOR` встанет перед `sensor`.

Сортировка по своему признаку — через `key`:

```python
order = sorted(counts, key=lambda name: -counts[name])
```

Минус разворачивает порядок: получилось «по убыванию количества».

Два признака сразу — кортежем. Сначала сравнивается первый, при равенстве второй:

```python
order = sorted(counts, key=lambda name: (-counts[name], name))
```

Это и есть «по убыванию количества, при равенстве по алфавиту».

## 6. Функции

```python
def average(values):
    """Среднее по списку чисел."""
    return sum(values) / len(values)
```

`def` объявляет, в скобках — что принимает, `return` — что отдаёт. После `return` функция заканчивается.

Функция должна делать одно дело и называться так, чтобы по имени было понятно какое. `process`, `do_all` и `func2` — плохие имена: они не говорят ничего.

Возвращать можно несколько значений сразу:

```python
def parse(line):
    return reason, name, value


reason, name, value = parse(line)
```

## 7. Свой модуль и импорт

Модуль — это просто файл `.py`. Если рядом с `main.py` лежит `memory.py`, его можно подключить:

```python
import memory

lines = memory.read_lines(path)
```

либо взять из него отдельные имена:

```python
from memory import read_lines, classify

lines = read_lines(path)
```

Работает это потому, что Python ищет модули в папке запущенной программы. Оба файла лежат в `src/` — значит `main.py` найдёт `memory.py`. Файл `__init__.py` для этого не нужен.

**В модуле не должно быть `print`.** Модуль считает и возвращает, печатает точка входа. Модуль, который печатает сам, нельзя вызвать дважды по-разному: он всегда говорит одно и то же в одно и то же место.

## 8. Два потока вывода

У программы два выхода наружу. Стандартный вывод — для результата. Поток ошибок — для всего, что результатом не является: предупреждений, счётчиков, сообщений о проблемах.

```python
import sys

print("POWER | 2 | 13.000")
print("значение не число 7", file=sys.stderr)
```

Зачем это нужно, видно из команды:

```
python3 src/main.py datasets/memory.log > src/report.txt
```

Стрелка забирает в файл только стандартный вывод. Отчёт уезжает в файл, счётчики остаются на экране. Если бы всё шло в один поток, файл отчёта был бы испорчен строками про причины.

## 9. Исключения

Некоторые операции не возвращают ошибку, а останавливают программу. `int("три")` не даёт «ничего» — он останавливает всё.

Перехватить это:

```python
try:
    number = float(value)
except ValueError:
    number = None
```

`try` — попробовать, `except ValueError` — что делать, если случилась именно эта ошибка.

**Где не надо.** Один `try` вокруг всей программы — худшее, что можно сделать: он ловит всё подряд, и ты перестаёшь понимать, что именно сломалось и где. Оборачивай одну операцию, от которой ждёшь конкретную ошибку.

**Голое `except:` без имени ошибки** ловит вообще всё, включая твои собственные опечатки, и прячет их. Всегда называй ошибку.

И помни: проверить заранее часто лучше, чем ловить. Вчерашняя проверка «это число или нет» никуда не делась и работает быстрее исключения.

## 10. Числа и вывод

| Что пишем | Что получаем |
| --- | --- |
| `"%.3f" % 20.4333` | `20.433` |
| `f"{value:.3f}"` | то же самое |
| `"%s | %d | %s" % (name, count, average)` | строка с подстановками |
| `float("21.4")` | `21.4` |
| `int("42")` | `42` |
| `sum(values) / len(values)` | среднее |

Деление на ноль останавливает программу: у модуля без принятых записей среднего не существует, и считать его нельзя.

Округляй только при печати. Если округлить каждое значение до трёх знаков, а потом усреднить, результат разойдётся с эталоном.
