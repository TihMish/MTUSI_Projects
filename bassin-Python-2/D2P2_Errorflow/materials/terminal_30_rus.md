## 1. Где я и что вокруг

| Команда | Что делает |
| --- | --- |
| `pwd` | Печатает, в какой папке ты сейчас находишься |
| `ls` | Показывает файлы и папки здесь |
| `ls -l` | То же, но с правами, размером и датой — по строке на файл |
| `ls -a` | Показывает и скрытые файлы, имена которых начинаются с точки |
| `ls путь` | Показывает содержимое другой папки, не переходя в неё |
| `cd имя` | Переходит в папку |
| `cd ..` | Поднимается на уровень выше |
| `cd` | Возвращает в домашнюю папку |

Путь без ведущей косой черты считается от текущей папки: `src/partner` — это папка `partner` внутри `src` внутри той, где ты стоишь. Путь с косой чертой в начале считается от корня диска.

Почти все ошибки вида «файл не найден» лечатся командой `pwd`.

## 2. Как посмотреть файл

| Команда | Что делает |
| --- | --- |
| `cat файл` | Печатает файл целиком |
| `cat -A файл` | То же, но показывает невидимое: `$` в конце каждой строки, `^I` вместо табуляции. Так проверяют лишний перенос строки |
| `head -n 5 файл` | Первые пять строк |
| `tail -n 5 файл` | Последние пять строк |
| `wc -l файл` | Сколько строк в файле |
| `grep текст файл` | Печатает строки, в которых встречается текст |

`cat -A` — единственный способ увидеть, заканчивается вывод переносом строки или нет.

## 3. Запуск и код возврата

| Команда | Что делает |
| --- | --- |
| `python3 файл.py` | Запускает программу |
| `python3 файл.py арг1 арг2` | Запускает и передаёт ей аргументы |
| `bash файл.sh` | Выполняет файл с командами терминала |
| `echo $?` | Печатает код возврата **последней** завершившейся команды |

Каждая программа, завершаясь, оставляет число — код возврата. Ноль означает «всё прошло как задумано», любое другое число — «что-то пошло не так». На экране этого числа не видно, его надо спросить.

```
python3 src/partner/boot.py
echo $?
```

`echo $?` показывает результат только той команды, которая выполнилась прямо перед ним. Запустишь что-нибудь ещё — число сменится.

## 4. Перенаправление

| Команда | Что делает |
| --- | --- |
| `программа < файл` | Программа читает из файла вместо клавиатуры |
| `программа > файл` | Вывод программы кладётся в файл, старое содержимое стирается |
| `программа >> файл` | Вывод дописывается в конец файла |
| `echo текст > файл` | Записывает строку в файл |
| `echo текст >> файл` | Дописывает строку в конец файла |

```
python3 src/hello.py < одна_строка.txt
```

Через `echo` с двумя стрелками удобно накапливать файл с командами, ничего не открывая:

```
echo "ls -l src/partner" >> src/quest1.sh
```

## 5. Создать, скопировать, удалить

| Команда | Что делает |
| --- | --- |
| `mkdir имя` | Создаёт папку |
| `mkdir -p a/b/c` | Создаёт всю цепочку папок сразу |
| `touch файл` | Создаёт пустой файл |
| `cp откуда куда` | Копирует файл |
| `mv откуда куда` | Перемещает или переименовывает |
| `rm файл` | Удаляет файл |
| `rm -r папка` | Удаляет папку со всем содержимым |

`rm` ничего не переспрашивает и никуда не откладывает. Удалённое не возвращается. Перед удалением по маске полезно сначала посмотреть, что под неё попадёт, той же маской с `ls`.

## 6. Маски

Маска — это шаблон имени. Терминал сам подставит вместо неё все подходящие файлы.

| Маска | Что означает | Пример совпадения |
| --- | --- | --- |
| `*` | Любое количество любых символов | `dump/*` — всё в папке |
| `chunk*` | Всё, что начинается с `chunk` | `chunk0007.dat` |
| `*.dat` | Всё, что заканчивается на `.dat` | `chunk0007.dat` |
| `part???.frag` | `part`, ровно три любых символа, `.frag` | `part017.frag` |
| `noise*` | Всё, что начинается с `noise` | `noise03.frag` |

```
ls dump/chunk*
rm dump/chunk*
```

Одна маска убирает сотню файлов. Решение, написанное маской, переживёт другой набор файлов; решение, где имена перечислены руками, — нет.

## 7. Права

| Команда | Что делает |
| --- | --- |
| `ls -l файл` | Показывает права первой колонкой, например `-rw-r--r--` |
| `chmod +x файл` | Разрешает запускать файл |
| `chmod -x файл` | Запрещает запускать файл |

В строке `-rwxr--r--` первые три буквы после дефиса — права владельца: `r` читать, `w` изменять, `x` запускать. Если `x` нет, файл нельзя запустить командой `./файл`. Запуск через `python3 файл.py` или `bash файл.sh` прав на выполнение не требует.

## 8. Редактор в терминале

`nano файл` открывает простой редактор.

| Клавиши | Что делают |
| --- | --- |
| Стрелки | Перемещение по тексту |
| Ctrl+O, затем Enter | Сохранить |
| Ctrl+X | Выйти |
| Ctrl+K | Вырезать строку |
| Ctrl+W | Найти текст |

Подписи внизу экрана: `^` означает Ctrl.

Если случайно оказался в `vim` и не знаешь, как выйти: нажми Esc, набери `:q!` и нажми Enter — выйдешь без сохранения.

## 9. Когда команда ругается

| Ответ терминала | Что означает | Что попробовать |
| --- | --- | --- |
| `command not found` | Такой команды нет: опечатка или программа не установлена | Проверь написание. `python` и `python3` — разные команды |
| `No such file or directory` | Файла или папки с таким именем здесь нет | `pwd` и `ls`: скорее всего, ты не в той папке |
| `Permission denied` | Нет прав | `ls -l` и `chmod`, либо запускай через `python3` или `bash` |
| `Is a directory` | Ты обращаешься с папкой как с файлом | Проверь путь |
| `Directory not empty` | `rmdir` не удаляет непустую папку | `rm -r` |
| Ничего не происходит, курсор мигает | Программа ждёт от тебя ввод | Введи строку и нажми Enter. Прервать — Ctrl+C |
| Строка начинается с `>` и не заканчивается | Не закрыта кавычка | Ctrl+C и набери команду заново |

Ctrl+C прерывает то, что сейчас выполняется. Это не поломка, а обычный способ остановить программу.
