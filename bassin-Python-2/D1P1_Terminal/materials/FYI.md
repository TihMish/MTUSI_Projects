# Материалы дня

Начни с START_HERE.md. Полная карта справочников — в README.md, структура файлов — в materials/map_rus.txt. Все обязательные материалы лежат локально в этом комплекте. Служебные документы авторам и эталонные решения для прохождения не нужны.

| Файл | Для чего |
| --- | --- |
| `START_HERE.md` | Получение всех заданий, локальная выдача и сдача |
| `materials/rules_rus.md` | Правила самостоятельной работы и оценки |
| `materials/terminal_30_rus.md` | Пути, запуск, потоки, редактор, маски, shell-аргументы |
| `materials/git_scenarios_rus.md` | Коммиты, ветки, слияние, перенос без сети |
| `materials/python_day01_rus.md` | Ввод, проверка чисел, арифметика, условия, вывод |
| `materials/traceback_40_rus.md` | Чтение ошибок и варианты экспериментов |
| `materials/stuck_rus.md`, `materials/glossary_rus.md` | Что делать в тупике, значения терминов |
| `materials/peer_review_rus.md` | Команды пиринговой проверки и практические карточки |
| `datasets/inputs.txt`, `datasets/expected.txt` | Шесть контрольных входов и ответы для трёх программ |
| `datasets/cases.json` | Все точные автоматизируемые примеры проверки |
| `src/partner/` | Память, загрузчик, генератор и сборщик дампа |
| `templates/` | Формат журнала, HOWTO, личной карточки и протокола проверки |
