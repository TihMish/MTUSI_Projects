# Ориентир для HOWTO

Напиши собственный src/HOWTO.md с проверенными командами. Проверяющий начинает в новой пустой папке, располагая submission.bundle. Пусть для воспроизведения он копирует bundle прямо в эту папку — тогда внешние абсолютные пути не нужны.

Минимальный маршрут:

```bash
git clone --branch develop submission.bundle project
cd project
python3 src/partner/boot.py
echo $?
```

Дополни команды запуском всех трёх своих скриптов с конкретными входами и точными ожидаемыми ответами. Укажи программы и способ проверить отсутствие переноса. Не требуй сети, доступа к серверу или установки пакетов. Сначала сам повтори инструкцию в отдельной папке.
