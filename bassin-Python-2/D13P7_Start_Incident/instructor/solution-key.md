Доказательством является разница: сервер умеет требовать авторизацию и на этом пути её не требует. Размер отданного файла **366 887 байт** — ровно столько, сколько записано в журнале в событии `http_get`.

**4. Токен.** `EXP-9f3a7c21b8e4`, коммит `c4d9e1a`, автор Константин Ефимов, дата 2026-07-28 14:22:37 +0300. На стенде: `curl -H "X-Auth-Token: EXP-9f3a7c21b8e4" http://127.0.0.1:8013/api/config` → **200** и конфиг с путём бэкапов и списком учёток. Без заголовка → 401, с произвольным значением → 403. | seq | ts | action |
|---|---|---|
| 90 | 2026-09-09T01:17:08Z | `session_open`, peer 45.132.19.88 |
| 91 | 2026-09-09T01:17:10Z | `heartbeat`, queue 0 ← **подменена** |

**Что это доказывает:** содержимое записи изменено после её создания. **Чего не доказывает:** кто именно её изменил. Ответ «доказано, что Смотритель врёт» без этой оговорки — неполный; ответ «значит, Смотритель и есть злоумышленник» — неверный.
