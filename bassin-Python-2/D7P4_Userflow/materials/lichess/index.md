# Каталог скриншотов Lichess

Десять скриншотов доступны в отдельной папке на учебной платформе `/misc`. В этом каталоге используются исходные имена файлов: переименовывать изображения не требуется. Открой нужные кадры в папке платформы или скачай их для локального просмотра. Доступ к самому Lichess для задания не нужен.

Точная дата съёмки и масштаб браузера не сообщены. На кадрах видны светлая тема, русская навигация и предложения входа или регистрации. Некоторые тексты на английском сохранены как на исходных изображениях.

Новая волна пользователей в задании — учебная ситуация. Кадры показывают возможности и отдельные состояния современного интерфейса; они не являются записью непрерывной пользовательской сессии.

## Состав набора

| Имя файла | Экран |
|-----------|-------|
| `main.png` | Главная страница с залом ожидания |
| `main_menu_1.png` | Раскрытое меню «Игра» |
| `main_menu_2.png` | Раскрытое меню «Задачи» |
| `game_setting_1.png` | Параметры запроса на игру |
| `game_setting_2.png` | Параметры игры с компьютером |
| `game_analysis.png` | Требование регистрации после запроса компьютерного анализа |
| `chess_education.png` | Каталог «Основы шахмат» |
| `practice.png` | Каталог «Практика» |
| `chess_riddles.png` | Задача после успешного решения |
| `registration.png` | Видимая часть формы регистрации |

## Как выбрать материал для сценария

| Что изучаешь | Какие файлы использовать |
|--------------|--------------------------|
| Выбор игры и её параметров | `main.png`, `main_menu_1.png`, `game_setting_1.png`, `game_setting_2.png` |
| Выбор обучения или практики | `main.png`, `chess_education.png`, `practice.png`; меню обучения видно на двух последних кадрах |
| Доступные действия после решённой задачи | `main_menu_2.png`, `chess_riddles.png` |
| Предложения создать аккаунт | `practice.png`, `chess_riddles.png`, `registration.png` |
| Запрос компьютерного анализа и сообщение о необходимости регистрации | `game_analysis.png`; видимая часть формы — `registration.png` |

Для учебной ситуации можешь считать, что пользователь находится в состоянии `main.png`.
