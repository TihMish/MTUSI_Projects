# HTML для прототипа пользовательского пути

Эта справка поможет прочитать небольшой HTML-файл, изменить текст и настроить переходы между экранами. Для работы нужны текстовый редактор и браузер. Пример ниже открывается локально, без установки программ и подключения к интернету.

## Как браузер собирает экран

HTML — язык разметки: он описывает содержимое страницы и его структуру. Тег `<h1>` обозначает главный заголовок, `<p>` — абзац, `<button>` — кнопку. Браузер читает файл и отображает эти элементы.

CSS задаёт оформление: размеры, цвета, отступы. JavaScript описывает поведение: например, после нажатия кнопки скрывает один экран и показывает другой. В нашем примере все три части находятся в одном файле `index.html`.

## Что понадобится

В HTML используются теги и атрибуты. В записи `<button type="button">Продолжить</button>` открывающий и закрывающий теги окружают текст кнопки, а атрибут `type` задаёт её тип.

| Запись | Назначение |
| --- | --- |
| `<h1>…</h1>`, `<h2>…</h2>` | Заголовок страницы и заголовок раздела |
| `<p>…</p>` | Абзац текста |
| `<section>…</section>` | Раздел; в примере каждый раздел представляет один экран |
| `<button type="button">…</button>` | Кнопка; действие для неё задаём отдельно |
| `<a href="help.html">Справка</a>` | Ссылка на другой файл или адрес |
| `id="screen-start"` | Уникальное имя элемента, по которому его находит код |
| `hidden` | Скрывает элемент; для показа атрибут нужно убрать |
| `onclick="showScreen('screen-next')"` | При нажатии вызывает функцию `showScreen` с именем нужного экрана |
| `<style>…</style>` | CSS с правилами оформления |
| `<script>…</script>` | JavaScript с поведением страницы |

## Два экрана в одном файле

Скопируй пример в текстовый редактор и сохрани как `index.html` в кодировке UTF-8. Открой файл браузером. Кнопки переключают два заранее подготовленных экрана.

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Запись в мастерскую</title>
  <style>
    body { font-family: sans-serif; max-width: 640px; margin: 32px auto; padding: 16px; }
    button { font: inherit; padding: 12px 16px; cursor: pointer; }
    button:focus-visible { outline: 3px solid #1755b0; outline-offset: 3px; }
  </style>
</head>
<body>
  <main>
    <section id="screen-start">
      <h1 tabindex="-1">Запись в мастерскую</h1>
      <p>Ближайшее свободное время — завтра в 12:00.</p>
      <button type="button" onclick="showScreen('screen-next')">
        Выбрать завтра в 12:00
      </button>
    </section>

    <section id="screen-next" hidden>
      <h2 tabindex="-1">Выбрано завтра в 12:00</h2>
      <p>На следующем шаге потребуется указать имя и способ связи.</p>
      <button type="button" onclick="showScreen('screen-start')">
        Вернуться к выбору времени
      </button>
    </section>
  </main>

  <script>
    function showScreen(screenId) {
      document.querySelectorAll('main > section').forEach(function (screen) {
        screen.hidden = screen.id !== screenId;
      });
      document.querySelector('#' + screenId + ' h1, #' + screenId + ' h2').focus();
    }
  </script>
</body>
</html>
```

В `<head>` находятся служебные сведения и оформление, в `<body>` — видимое содержимое. Функция `showScreen` перебирает экраны и оставляет видимым только экран с переданным `id`. Затем переводит фокус на его заголовок. `tabindex="-1"` позволяет сделать это из кода, не добавляя заголовок в обычный обход клавишей Tab.

## Как поправить результат

- **Изменить надпись:** найди её поиском в редакторе и замени текст между тегами.
- **Изменить переход:** в `showScreen('screen-next')` укажи `id` целевого экрана. Имена должны совпадать с учётом регистра.
- **Добавить экран:** скопируй целиком один `<section>…</section>` внутрь `<main>`, задай новый уникальный `id`, добавь `hidden`, измени содержимое и направь на него кнопку.
- **Увеличить текст или отступы:** поправь CSS в `<style>`. Например, `padding: 12px 16px` задаёт внутренние отступы сверху и снизу, затем слева и справа.

После изменения сохрани файл и обнови страницу браузера. `hidden="false"` тоже скрывает элемент: чтобы показать его в исходном HTML, убери атрибут целиком.

## Как использовать ИИ

Сначала опиши экраны своими словами: цель пользователя, текст каждого экрана, названия кнопок и назначения переходов. Передай модели этот список и попроси собрать один локальный HTML-файл со встроенными CSS и JavaScript, без внешних зависимостей. Можно приложить пример из этой справки.

Проверь полученный файл в браузере. Если неверна подпись или адрес перехода, найди нужное место в коде и поправь его. Если нужна помощь модели, передай небольшой фрагмент, опиши ожидаемое действие и то, что происходит сейчас. Так проще контролировать изменение и расходовать меньше запросов, чем при повторной генерации всей страницы.

Пройди все предусмотренные маршруты, включая возврат. Проверь кнопки клавишами Tab и Enter. Если что-то не работает, открой инструменты разработчика браузера и вкладку Console: сообщение об ошибке поможет найти причину. Пример демонстрирует переходы; настоящая запись в мастерскую в нём не создаётся.
