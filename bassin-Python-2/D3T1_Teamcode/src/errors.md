# Общий журнал ошибок

Продолжается с первых двух дней. Записи подписаны: видно, чья ошибка.

Формат записи: участник · команда или действие · сообщение как есть · причина ·
исправление · повторная проверка.

Обязательного числа записей нет. Успешная проверка с первого раза — тоже запись.
Выдумывать поломки не нужно.
