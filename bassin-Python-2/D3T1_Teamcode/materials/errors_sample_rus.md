# Общий журнал ошибок

Запись: участник · команда/действие · сообщение как есть · причина · исправление · повторная проверка.

Пример:

```text
Анна · запуск --scan · KeyError: 201 · у вопроса нет списка ответов ·
проверена связь перед обращением · битых стало на один больше, чтение завершилось
```

Записывайте по ходу работы. Реальный текст traceback можно сохранить отдельным
блоком в errors.md. Обязательного числа ошибок нет; успешная проверка тоже может
быть записью. Не нужно специально портить программу ради журнала.
Из прежних журналов перенесите полезные записи с авторами; не требуется механически
объединять все одинаковые ошибки четырёх участников.
