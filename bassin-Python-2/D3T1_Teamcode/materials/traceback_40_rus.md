# Ошибки: как читать traceback и 40 диагностических случаев

Читайте последнюю строку traceback: тип исключения и сообщение. Затем найдите
последний кадр, указывающий на ваш файл, и номер строки. Проверьте значения
операндов и путь выполнения. Исключение показывает место проявления; причина
может находиться раньше. Исправьте минимальный пример и повторите исходный запуск.

```text
Traceback (most recent call last):
  File "demo.py", line 2, in <module>
    value = int(raw)
ValueError: invalid literal for int() with base 10: 'abc'
```

Здесь преобразование не принимает `abc`. Если плохой ввод ожидаем, проверяйте
или перехватывайте `ValueError` рядом с преобразованием. Не прячьте все ошибки
всей программы одним `except Exception: pass`. Для отладки временно печатайте
`repr(value)` и `type(value)` в stderr; уберите отладочную печать перед сдачей.

| № | Симптом | Что проверить / сделать |
|---|---|---|
| 1 | SyntaxError: invalid syntax | Предыдущую строку, двоеточие, скобки, кавычки |
| 2 | SyntaxError: unterminated string literal | Закрыть строковую кавычку; перенос представить через `\n` |
| 3 | SyntaxError: '(' was never closed | Найти незакрытую скобку |
| 4 | IndentationError: expected an indented block | Добавить тело блока с отступом |
| 5 | IndentationError: unexpected indent | Убрать лишний уровень отступа |
| 6 | TabError | Заменить смешанные табуляции и пробелы четырьмя пробелами |
| 7 | NameError | Имя, регистр, момент присваивания |
| 8 | UnboundLocalError | Во всех ли ветках локальной переменной присвоено значение |
| 9 | TypeError при сложении строки и числа | Преобразовать ввод; не маскировать число строкой в расчёте |
| 10 | TypeError: object is not callable | Не затёрты ли `list`, `str`, `input` своими переменными |
| 11 | TypeError: missing required positional argument | Сигнатуру функции и число аргументов |
| 12 | TypeError: object is not subscriptable | Не возвращает ли функция None вместо списка |
| 13 | TypeError при сравнении None и числа | Отдельно обработать отсутствие уровня |
| 14 | ValueError в int | Пустую строку, знак, нечисловой текст |
| 15 | ValueError при распаковке | Число полей после split; сначала проверить длину |
| 16 | IndexError | Размер списка и границу индекса: последний индекс len − 1 |
| 17 | KeyError | Есть ли ключ; использовать проверку `in` или осмысленный `.get` |
| 18 | AttributeError | Тип объекта, имя метода, возможный None |
| 19 | ZeroDivisionError | Пустой список / нулевой знаменатель до деления |
| 20 | FileNotFoundError | cwd, относительный путь, написание имени; файл может отсутствовать по заданию |
| 21 | IsADirectoryError | Не передана ли папка вместо файла |
| 22 | NotADirectoryError | Не используется ли файл как часть пути к папке |
| 23 | PermissionError | Доступ к конкретному пути; работать в своём репозитории |
| 24 | UnicodeDecodeError | Читать текст с encoding='utf-8'; не считать двоичный файл текстом |
| 25 | UnicodeEncodeError | Кодировку окружения и канала вывода |
| 26 | ModuleNotFoundError | Имя локального модуля, путь, папку запуска; pip проекту не нужен |
| 27 | ImportError о partially initialized module | Циклические импорты; согласовать направление зависимостей |
| 28 | EOFError в input | Штатно остановить сессию по протоколу; пустая строка и EOF различны |
| 29 | JSONDecodeError | Ответ в логе должен быть результатом json.dumps, а не ручных кавычек |
| 30 | BrokenPipeError | Читатель закрыл канал; отдельно выяснить, почему проверяющий остановил процесс |
| 31 | Программа молчит | Ждёт ввод, зациклилась или не сброшен буфер stdout |
| 32 | Проверяющий сообщает таймаут | `print(..., flush=True)` перед ожиданием ответа; отсутствие цикла без выхода |
| 33 | Получается None | Нет return или результат `.append()` ошибочно сохранён как список |
| 34 | Два списка меняются вместе | `b = a` связывает два имени с одним списком |
| 35 | Пропали элементы при обходе | Не удалять элементы из обходящегося списка; собрать новый |
| 36 | Сравнение выглядит верным, но не проходит | `repr`: пробелы, переносы, кириллическая А и латинская A |
| 37 | Ответ many проверяется странно | По этому протоколу порядок и повторы несущественны; неизвестная метка даёт не принят |
| 38 | При одинаковом seed результат разный | Порядок кандидатов, другие источники случайности, общее состояние между запусками |
| 39 | Счётчики переписи не сходятся | Не включены ли битые в тематические срезы; одна запись с двумя ошибками считается один раз |
| 40 | Удалённый вопрос всё ещё виден | Верный путь банка, сохранённый файл, отсутствие старого кэша / другой копии |

Формулировка сообщения зависит от версии Python. Учите причину, а не текст наизусть.
В `src/errors.md` достаточно реальных полезных записей: действие, сообщение,
причина, исправление, повторная проверка. Создавать сорок искусственных ошибок не нужно.
