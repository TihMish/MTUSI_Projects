# Темы и уровни

| Тема | Материал |
|---|---|
| ввод | input, print, strip, split, преобразование чисел, проверки, stdout/stderr |
| данные | Списки, словари, поля, счётчики, группировка, сумма и среднее |
| ошибки | Имена исключений, try/except, traceback, продолжение после неверной записи |
| структура | Функции, аргументы, return, импорт, разделение вычисления и печати |

| Уровень | Действие | Пример формы вопроса |
|---|---|---|
| 1 | Узнать имя или назначение | Как называется исключение деления на ноль? |
| 2 | Применить знакомое правило к новым значениям | Каков результат int для конкретной строки? |
| 3 | Выбрать сочетание известных действий | Где поставить try, чтобы продолжить чтение файла? |
| 4 | Проследить исполнение и изменение состояния | Каков вывод небольшого цикла с заданными значениями? |
| 5 | Найти контрпример/условие нарушения договора | Какой допустимый вход неверно отвергает данная проверка? |

Уровень не определяется длиной текста. Для 2 достаточно прямого применения
указанного правила; для 4 требуется проследить несколько шагов состояния.
Вопрос output с заданным входом в этом комплекте относится к 4, а не к 5.
Вопрос 5 должен требовать контрпримера или условия поломки, а не только трассировки.
Одна тема может содержать все уровни. Эталонные вопросы показывают принятые границы.

Собственные вопросы опираются на материал дней 1–2. Не проверяйте классы,
декораторы, генераторы, сторонние библиотеки, технические тонкости конкретной
версии Python или Git. Новые приёмы реализации дня 3 не обязаны становиться
темами теста. Если граница уровня спорна, уточните формулировку и обоснование.
