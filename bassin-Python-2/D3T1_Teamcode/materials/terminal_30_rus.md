# Терминал: 30 приёмов без интернета

Команды рассчитаны на Bash в Linux. `ПАПКА` и `ФАЙЛ` заменяйте своими именами;
это не буквальные имена из выдачи. Начинайте из корня командного репозитория.
Относительный путь отсчитывается от текущей папки; абсолютный начинается с `/`.

| № | Команда / действие | Что происходит |
|---|---|---|
| 1 | `pwd` | Показать текущую папку |
| 2 | `ls` | Показать имена файлов |
| 3 | `ls -l` | Имена, размеры и права |
| 4 | `ls -a` | Включить имена с начальной точкой |
| 5 | `cd ПАПКА` | Перейти в папку |
| 6 | `cd ..` | Перейти в родительскую папку |
| 7 | `cd -` | Вернуться в предыдущую папку |
| 8 | `mkdir -p tmp/run1` | Создать вложенные папки |
| 9 | `cp ФАЙЛ tmp/` | Скопировать файл |
| 10 | `cp -r datasets tmp/bank` | Скопировать банк в ещё не существующую папку |
| 11 | `mv СТАРОЕ НОВОЕ` | Переместить или переименовать; проверьте цель |
| 12 | `rm tmp/ФАЙЛ` | Удалить конкретный временный файл без корзины |
| 13 | `rmdir tmp/ПАПКА` | Удалить только пустую папку |
| 14 | `cat src/HOWTO.md` | Напечатать файл |
| 15 | `head -n 10 datasets/bank_reference.txt` | Первые десять строк |
| 16 | `tail -n 10 tmp/log.txt` | Последние десять строк |
| 17 | `wc -l datasets/bank_reference.txt` | Посчитать строки; комментарии тоже считаются |
| 18 | `grep -n '203' datasets/bank_review.txt` | Найти текст и номера строк; совпадение ещё не проверка ID |
| 19 | `python3 --version` | Уточнить установленную версию Python |
| 20 | `git --version` | Уточнить установленную версию Git |
| 21 | `python3 src/main.py datasets/ --scan` | Запустить перепись банка |
| 22 | `python3 src/main.py datasets/ --seed 4711 > tmp/session.txt` | Сохранить stdout; `>` перезаписывает файл |
| 23 | `python3 src/main.py datasets/ --seed 4711 2> tmp/log.txt` | Сохранить stderr; вопросы останутся на экране |
| 24 | `python3 src/main.py datasets/ < tmp/answers.txt` | Читать ответы из файла по одной строке |
| 25 | `cat tmp/log.txt >> tmp/all_logs.txt` | Дописать вывод в конец файла |
| 26 | `diff tmp/run1.txt tmp/run2.txt` | Показать различия двух текстов; пустой вывод означает совпадение |
| 27 | `echo $?` сразу после программы | Её код завершения: обычно 0 — успех |
| 28 | `Ctrl-C` | Прервать процесс; это не штатный EOF |
| 29 | `Ctrl-D` на пустой строке | Передать EOF при ручном вводе |
| 30 | `Tab`, стрелка вверх, `Ctrl-A` / `Ctrl-E` | Дополнить имя, вернуть прошлую команду, начало / конец строки |

Создайте `tmp/` до перенаправления туда. Пути с пробелами заключайте в двойные
кавычки. Не копируйте в терминал приглашение `$`, если оно показано в примере.
При перенаправлении stdout вопросы не видны, но ввод может всё ещё ожидаться:
для автоматических опытов удобнее `examiner.py --play`.

Python-программа получает аргументы через `sys.argv`; это строки. Не путайте
команду Bash `python3 src/main.py ...` с выражением Python: первое вводят в
терминале, второе — в файле `.py` или интерактивном Python. `exit()` выходит из Python.

Новые внешние программы устанавливать не нужно. Документы проекта содержат
все используемые команды Git и Python. Внутренний URL репозитория берите с платформы.
