# Малый технический банк

Банк small_bank/ демонстрирует четыре типа и вопрос вне шкалы. Он предназначен
для проверки формата и функций, не для ревизии и не для измерения уровня.
Его технические формулировки не являются содержательным образцом новых вопросов.

Из корня командного репозитория:

```sh
python3 src/main.py examples/small_bank/ --scan
```

Ожидаемый stdout: small_scan_expected.txt. Битость можно проверить во временной
копии, удалив ответы вопроса 11: всего остаётся 5, битых становится 1,
число исправных one уменьшается с 1 до 0, уровень 1 — с 1 до 0.
Команда --bank-check для этого демонстрационного банка не применяется:
она проверяет итоговый банк 50 + сохранённые review + 20 team.
