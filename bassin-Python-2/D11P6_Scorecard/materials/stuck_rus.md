# Если застрял

## Не могу открыть базу

Проверь, что терминал находится в корне проекта, рядом с README.md. Открой RUN.md. Если prepare.py сообщает об отсутствии Python или поддержки SQLite, обратись к стаффу. Не устанавливай пакеты наугад.

## Не знаю правильного ответа

Уменьши задачу. Посмотри строки одной таблицы, затем добавь связь с другой. Назови, что значит одна строка результата. Для неоднозначного вопроса проверь два толкования. Не начинай атаку, пока сам не понимаешь, чего ожидаешь.

## Модель не ошибается

Это допустимый результат. Проверь пропуски, совпадающие имена, несколько версий отчёта, единицы измерения. Не меняй ожидание после ответа только ради fail. Сохрани честный pass и переходи дальше по плану.

## Не понимаю различие dimensions

Спроси себя: выбраны не те данные, неправильно посчитаны выбранные данные, придуман неизвестный факт или молча выбран смысл вопроса? Устойчивость требует двух ответов. Один случай может затронуть несколько сторон.

## Ответ модели длинный

Не сокращай исходный ответ. Вставь его в журнал целиком. Короткое объяснение ошибки запиши отдельно в причине оценки. Для доказательства обычно достаточно нескольких конкретных строк базы.

## SQL модели не запускается

Сохрани SQL и точную ошибку. Ошибка синтаксиса сама по себе ещё не говорит, какой dimension нарушен. Объясни её связь с твоим заранее записанным правилом. При необходимости поставь unclear.

## Отчёт показывает слишком много ответов

Проверь JOIN: один ответ мог повториться из-за нескольких оценок. Посчитай отдельно число строк attempts и число строк assessments. Для устойчивости считай pairs.

## Не успеваю всё

Доведи один случай от ожидания до доказательства и покажи, где остановился. Не выдумывай недостающие попытки. Основная часть важнее бонусов. На P2P можно обсудить выполненную часть отдельно.
