# Запуск проекта

Все команды выполняются из корня проекта. Используется только уже установленный Python со стандартной библиотекой. Интернет нужен только для ручного общения с моделью в браузере.

## Подготовка

`python3 src/partner/prepare.py`

Команда сообщает версию Python и SQLite, открывает учебную базу и создаёт src/results.db. Существующий журнал не перезаписывается. Это подготовка файлов, а не проверка решения и не оценивание.

Если Python или sqlite3 недоступны, передай текст ошибки стаффу. Ничего не устанавливай самостоятельно.

## Просмотр таблиц

`python3 src/partner/query.py data/station.db --tables`

`python3 src/partner/query.py data/station.db --sql "SELECT * FROM experiments"`

## Запуск своего файла SQL

`python3 src/partner/query.py data/station.db --file src/explore.sql`

В файле может быть несколько запросов, разделённых точкой с запятой. Учебная база открывается только для чтения. Команды изменения данных и подключения других баз отклоняются. Очень длинный запрос остановится; вывод ограничен 200 строками на запрос. Ограничение помощника само по себе не считается ошибкой модели.

Для SQL из ответа модели создай временный файл src/model_query.sql и используй эту же команду с его именем. Не выполняй команды модели напрямую в рабочей базе результатов.

## Журнал

`python3 src/partner/journal.py`

Меню позволяет создать случай, формулировку, попытку, пару ответов, ручную оценку и заметку. Для длинного текста вставляй строки, затем напиши отдельной строкой :::END:::. Это служебная строка ввода, в текст она не входит.

Сначала создаётся случай, потом его формулировка, затем попытка. Номера выводятся после сохранения. Введённые оценки сохраняет человек; программа их не проверяет по смыслу.

`python3 src/partner/query.py src/results.db --tables`

`python3 src/partner/query.py src/results.db --sql "SELECT * FROM cases"`

Так можно читать свои записи. Меню не перезаписывает попытки. Ошибку ввода исправляй новой записью и поясняющей заметкой; для исправления случайно неверной оценки используй пункт меню 8 с обязательным комментарием. Если правильность оценки пока не ясна, выбери «спорно». История исправления сохраняется в notes.

## Своя программа

`python3 src/report.py`

Этот файл ты создаёшь в задании 6. При старте проекта его нет. Контракт вывода описан в README.md, точные подписи ты выбираешь сам.

## Сохранение

Закрой меню журнала перед добавлением файлов в Git. Добавь src/results.db вместе со своими .py и .sql. Не удаляй журнал для повторной подготовки: повторный запуск prepare.py безопасен и оставляет записи на месте.
