Как это работает: у каждого блока состояния есть свой id. Ссылка вида <a href="#loading"> ставит якорь в URL, а правило .state:target { display: block } показывает соответствующий блок и прячет остальные. Альтернатива — радиокнопки с псевдоклассом :checked.
