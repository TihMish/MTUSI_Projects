# Критерии оценки UI-текстов

1. **Понятность:** сможет ли пользователь без дополнительных пояснений понять, что произошло и что делать дальше?
2. **Краткость:** не длиннее ли сообщение, чем необходимо?
3. **Тон:** дружелюбный, но не фамильярный. Не обвиняет пользователя.
4. **Единообразие:** одинаковые термины во всём интерфейсе (например, не «переговорка» и «комната» одновременно).
5. **Полезность:** предлагает ли сообщение путь решения? (Не просто «Ошибка», а «Не удалось загрузить список. Проверьте подключение и попробуйте снова».)
6. **Видимость кнопок/ссылок:** если нужно действие, оно явно обозначено.

Проверяй каждый написанный тобой текст по этим пунктам. ИИ можно попросить «оцени этот UI-текст по критериям: понятность, краткость...» и получить альтернативу.
