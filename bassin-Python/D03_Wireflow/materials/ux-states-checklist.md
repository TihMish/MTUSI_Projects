# UX States Checklist

Используй этот список для каждого экрана. Отметь, какие состояния реализованы.

## Состояния
- [ ] Идеальное (First visit / loaded)
- [ ] Загрузка (Loading / Skeleton)
- [ ] Пустое состояние (Empty state — нет данных)
- [ ] Ошибка загрузки (Error — сервер недоступен, timeout)
- [ ] Частичная загрузка (Partial data)
- [ ] Конфликт / блокировка (Conflict / Already booked)
- [ ] Невалидный ввод (Validation error)
- [ ] Успех операции (Success feedback)
- [ ] Неавторизованный доступ (Unauthorized)
- [ ] Отсутствие соединения (Offline)

## Как использовать
Для каждого экрана пробегись по списку и реши, применимо ли данное состояние. Не все состояния нужны для каждого экрана, но ключевые (загрузка, ошибка, пустота) должны быть проработаны везде, где есть динамические данные.
