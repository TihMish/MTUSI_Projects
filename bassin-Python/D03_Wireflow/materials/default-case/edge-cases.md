# Edge Cases и сценарии обработки ошибок

## Список граничных случаев

| ID | Ситуация | Критичность | Сценарий обработки |
|----|----------|-------------|-------------------|
| EC-01 | Пользователь пытается забронировать слот в прошлом | Высокая | Система показывает сообщение: «Нельзя забронировать слот в прошлом. Выберите текущую или будущую дату». |
| EC-02 | Пользователь бронирует слот, который был занят во время отправки (race condition) | Высокая | Система показывает сообщение: «Слот был занят другим пользователем. Пожалуйста, выберите другой слот» и обновляет расписание. |
| EC-03 | Пользователь вводит количество участников больше вместимости комнаты | Высокая | Система показывает сообщение: «Количество участников превышает вместимость комнаты (максимум <число>)». |
| EC-04 | Пользователь не заполнил обязательное поле (название встречи) | Высокая | Система показывает сообщение: «Пожалуйста, заполните название встречи». |
| EC-05 | Комнат нет в системе (пустой список) | Средняя | Показывается сообщение: «В данный момент нет доступных комнат. Попробуйте позже». |
| EC-06 | Пользователь пытается забронировать 0 участников | Средняя | Показывается сообщение: «Количество участников должно быть больше 0». |
| EC-07 | Пользователь выбирает дату, на которую расписание не загружено | Низкая | Показывается сообщение: «Нет данных для выбранной даты». |
| EC-08 | Пользователь пытается забронировать слот без выбора комнаты | Низкая | Кнопка бронирования неактивна, пока не выбрана комната и слот. |
