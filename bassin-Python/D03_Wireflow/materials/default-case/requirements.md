# Требования к продукту

## Функциональные требования

### Для пользователя
1. Система должна отображать список всех доступных переговорных комнат с указанием их характеристик (название, вместимость, оснащение, расположение).
2. Система должна позволять пользователю фильтровать комнаты по вместимости, оснащению и названию.
3. Система должна показывать расписание комнаты на выбранную дату, выделяя свободные и занятые слоты.
4. Система должна позволять пользователю бронировать свободный слот, заполнив форму с названием встречи и количеством участников.
5. Система должна подтверждать успешное бронирование и показывать его детали.
6. Система должна сообщать об ошибке, если выбранный слот был занят в момент бронирования, и предлагать альтернативные слоты.

### Для администратора
7. Система должна позволять администратору добавлять, редактировать и удалять комнаты.
8. Система должна показывать администратору все бронирования в календарном виде.

## Нефункциональные требования
1. Интерфейс должен быть адаптивным (работать на десктопе и мобильных устройствах).
2. Страницы должны загружаться не более чем за 2 секунды при стандартном интернете.
3. Система должна корректно обрабатывать ошибки ввода пользователя (невалидные даты, пустые поля).
4. Интерфейс должен быть понятным для пользователей без дополнительного обучения.

## User Stories

### US-01: Просмотр списка комнат
**Как** пользователь, **я хочу** видеть список всех доступных переговорных комнат, **чтобы** выбрать подходящую для моей встречи.

**Критерии приёмки:**
- На главном экране отображаются все комнаты с названием, вместимостью и иконкой оснащения.
- При нажатии на комнату открывается её страница с деталями.

### US-02: Фильтрация комнат
**Как** пользователь, **я хочу** фильтровать комнаты по вместимости и оснащению, **чтобы** быстро найти подходящий вариант.

**Критерии приёмки:**
- Доступны фильтры: «Количество участников», «Оснащение (проектор, доска, Zoom)».
- После применения фильтров список обновляется, показывая только подходящие комнаты.

### US-03: Просмотр расписания комнаты
**Как** пользователь, **я хочу** видеть расписание выбранной комнаты на конкретную дату, **чтобы** понять, когда она свободна.

**Критерии приёмки:**
- На странице комнаты отображается календарь на выбранную дату (можно выбрать другую).
- Слоты отображаются с цветовой индикацией: свободные — зелёные, занятые — красные.
- При нажатии на свободный слот открывается форма бронирования.

### US-04: Бронирование слота
**Как** пользователь, **я хочу** забронировать свободный слот, **чтобы** гарантированно использовать комнату в нужное время.

**Критерии приёмки:**
- При выборе свободного слота открывается форма с полями: «Название встречи», «Количество участников».
- После отправки формы система создаёт бронирование и показывает подтверждение.
- Если слот был занят другим пользователем в момент отправки — показывается сообщение об ошибке с предложением выбрать другой слот.

### US-05: Подтверждение бронирования
**Как** пользователь, **я хочу** видеть подтверждение моего бронирования, **чтобы** быть уверенным, что комната зарезервирована.

**Критерии приёмки:**
- После успешного бронирования показывается экран с деталями: комната, дата, время, название встречи.
- На экране есть кнопка «Вернуться к списку комнат».

### US-06: Управление комнатами (админ)
**Как** администратор, **я хочу** добавлять, редактировать и удалять комнаты, **чтобы** поддерживать актуальный список ресурсов кампуса.

**Критерии приёмки:**
- В административном разделе доступны кнопки «Добавить комнату», «Редактировать», «Удалить».
- При добавлении комнаты заполняются поля: название, вместимость, оснащение, расположение, описание.
- После сохранения изменения отражаются в основном списке комнат.
