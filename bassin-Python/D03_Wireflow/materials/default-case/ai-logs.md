# Логи взаимодействия с ИИ (D01 — Планирование и прототипирование)

Дата: 01.01.2026

### 1. Уточнение цели и задачи продукта

**Промпт:**
> «Помоги уточнить цель и задачу продукта для сервиса бронирования переговорных комнат. Предложи 2–3 альтернативных формулировки и укажи, какая лучше подходит для MVP».

**Ответ ИИ (краткая выжимка):**
1. «Сервис для поиска и бронирования свободных переговорных комнат в кампусе».
2. «Платформа для управления расписанием переговорных и предотвращения конфликтов бронирования».
3. «Инструмент для быстрого бронирования комнат для встреч и созвонов».

**Комментарий:** Выбрал вариант 1, так как он наиболее точно отражает основную ценность продукта для пользователя.

### 2. Описание целевой аудитории

**Промпт:**
> «Опиши целевую аудиторию для сервиса бронирования переговорных комнат. Какие у неё явные и скрытые потребности?»

**Ответ ИИ (краткая выжимка):**
- **Студенты:** хотят быстро найти комнату для групповой работы. Скрытая потребность — чувство уверенности, что бронирование не пропадёт.
- **Сотрудники:** хотят бронировать комнаты для встреч без лишних согласований. Скрытая потребность — избежать неловких ситуаций, когда комната занята.

**Комментарий:** Дополнил портреты реальными сценариями из жизни кампуса.
