    [Главный экран]
          |
          | (выбор ресурса)
          ▼
   [Выбор ресурса/слота]
          |
          | (выбор времени)
          ▼
  [Подтверждение бронирования]
          |
          | (нажать "Забронировать")
          ▼

          ▼
