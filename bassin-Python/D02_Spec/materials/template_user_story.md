## Критерии приёмки (Acceptance Criteria)

*Критерии приёмки — это проверяемые условия, которые должны быть выполнены, чтобы user story считалась завершённой. Они должны быть чёткими, измеримыми и однозначными.*

1. **[Критерий 1]** — [Условие, которое должно выполниться. Пример: "На главной странице отображается календарь с возможностью выбора даты"]

2. **[Критерий 2]** — [Условие, которое должно выполниться. Пример: "После выбора даты отображается список доступных комнат"]

3. **[Критерий 3]** — [Условие, которое должно выполниться. Пример: "При попытке забронировать занятую комнату отображается сообщение об ошибке"]

4. **[Критерий 4]** — [Условие, которое должно выполниться. Пример: "Подтверждение бронирования приходит на email в течение 1 минуты"]
