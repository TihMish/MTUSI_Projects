# MTUSI_Projects

Портфолио учебных и проектных работ Анастасии Яшкольдиной.

Репозиторий организован ветками — каждая соответствует отдельному направлению обучения и сохраняет полную историю коммитов из исходных репозиториев.

## Структура веток

### `school21` — School 21 (Москва)

- **`bassin-C/`** — бассейн на C, ASCII Pong (9 проектов):
  D01T01, D02T02, D03T03, team-D05P01 (командный проект), D07T04, D08T05, D09T06, D10T07

- **`bassin-Python/`** — бассейн на Python:
  D01_Discovery, D02_Soft1, D02_Spec, D03_Wireflow

- **`project-management/`** — курс проектного менеджмента:
  PjM1-ProjPM

### `CU` — Центральный университет

- **`WikiGame/`** — проект "Тест-Драйв": поиск кратчайшего пути между статьями Википедии (Python, BFS)

### `yandex-litsey` — Яндекс Лицей

- **`Project_Yashkoldina_D23_QT/`** — проект на PyQt (D23)

## Как смотреть

Переключайся между ветками, чтобы увидеть работы по каждому направлению — каждая ветка самодостаточна и содержит только относящиеся к ней файлы и историю коммитов.
