# Портфолио — Анастасия Яшкольдина

Репозиторий собирает код и материалы к проектам, которые входят в портфолио для вуза. Организован по веткам — каждая соответствует источнику проекта.

## Структура веток

### `cu` — Центральный университет
Проекты и работы, выполненные в рамках программ ЦУ:
- **Тест-Драйв Центрального Университета** — январь–февраль
- **WikiGame: BFS vs Bidirectional BFS** — исследование эффективности BFS и двунаправленного BFS в задаче поиска пути в графе Wikipedia

### `school21` — School 21
Проекты, выполненные в рамках обучения в School 21 (язык C):
- **Game of Life (D12P02)** — реализация «Игры жизни» с ASCII/ncurses-визуализацией, интерактивный режим управления скоростью
- **pycellet** — командный проект, пошаговая ASCII-версия Pong

### `in-progress` — Текущее обучение
Проекты и лабораторные работы, которые добавляются по ходу дальнейшего обучения. Ветка обновляется по мере поступления новых работ.

## Как пользоваться

Каждая ветка содержит собственный README с описанием конкретного проекта, инструкцией по сборке/запуску и, где уместно, ссылкой на условие задания.
