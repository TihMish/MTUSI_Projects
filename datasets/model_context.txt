# Как устроена база станции

В базе семь таблиц.

| Таблица | Одна строка означает |
| --- | --- |
| people | Одного человека с уникальным person_id |
| experiments | Один опыт с уникальным experiment_id |
| participation | Участие одного человека в одном опыте |
| measurements | Одну запись измерения |
| equipment | Один физический прибор |
| inspections | Один осмотр прибора в определённый момент |
| reports | Одну версию отчёта по опыту |

## Люди и опыты

experiments.leader_id ссылается на people.person_id. Это руководитель опыта. participation связывает людей и опыты по person_id и experiment_id. Руководство и непосредственное участие учитываются отдельно.

Статус completed означает, что опыт завершён, running — идёт, cancelled — отменён. Отменённый опыт не считается завершённым. finished_at — момент завершения; у идущих и отменённых опытов он равен NULL.

Времена записаны в UTC в виде «год-месяц-день часы:минуты:секунды». Календарный месяц — время от первого числа этого месяца 00:00:00 включительно до первого числа следующего месяца 00:00:00 не включительно.

## Измерения

Каждая запись относится к одному опыту по experiment_id. metric называет величину, value хранит число, unit — единицу. quality бывает valid, suspect и missing. Это достоверная запись, сомнительная запись и неудавшееся измерение соответственно.

NULL в value означает «число не получено».

Единицы: kg — килограммы, g — граммы, 1 kg = 1000 g; C — градусы Цельсия, F — градусы Фаренгейта, для перехода из F в C вычти 32 и раздели на 1,8; percent — проценты, l/min — литры в минуту, pH — показатель кислотности, V — вольты, kPa — килопаскали.

## Приборы и осмотры

serial и equipment_id уникальны. Осмотр связан с прибором по equipment_id. ok — исправен при осмотре, broken — неисправен, unknown — состояние определить не удалось. У одного прибора нет двух осмотров с одинаковым временем.

## Отчёты

Отчёт связан с опытом по experiment_id. Для текущего вывода по опыту используется версия с наибольшим номером version. published_at — момент публикации версии. conclusion — текст наблюдения.

СХЕМА SQLITE
PRAGMA foreign_keys = ON;
CREATE TABLE people (
    person_id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    specialty TEXT NOT NULL
);
CREATE TABLE experiments (
    experiment_id INTEGER PRIMARY KEY,
    title TEXT NOT NULL,
    leader_id INTEGER NOT NULL REFERENCES people(person_id),
    status TEXT NOT NULL CHECK(status IN ('completed','running','cancelled')),
    started_at TEXT NOT NULL,
    finished_at TEXT
);
CREATE TABLE participation (
    experiment_id INTEGER NOT NULL REFERENCES experiments(experiment_id),
    person_id INTEGER NOT NULL REFERENCES people(person_id),
    role TEXT NOT NULL,
    PRIMARY KEY(experiment_id, person_id)
);
CREATE TABLE measurements (
    measurement_id INTEGER PRIMARY KEY,
    experiment_id INTEGER NOT NULL REFERENCES experiments(experiment_id),
    metric TEXT NOT NULL,
    value REAL,
    unit TEXT NOT NULL,
    measured_at TEXT NOT NULL,
    quality TEXT NOT NULL CHECK(quality IN ('valid','suspect','missing'))
);
CREATE TABLE equipment (
    equipment_id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    serial TEXT NOT NULL UNIQUE
);
CREATE TABLE inspections (
    inspection_id INTEGER PRIMARY KEY,
    equipment_id INTEGER NOT NULL REFERENCES equipment(equipment_id),
    inspected_at TEXT NOT NULL,
    condition TEXT NOT NULL CHECK(condition IN ('ok','broken','unknown'))
);
CREATE TABLE reports (
    report_id INTEGER PRIMARY KEY,
    experiment_id INTEGER NOT NULL REFERENCES experiments(experiment_id),
    version INTEGER NOT NULL,
    published_at TEXT NOT NULL,
    conclusion TEXT NOT NULL,
    UNIQUE(experiment_id, version)
);
